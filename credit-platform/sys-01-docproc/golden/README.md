# 金标数据集（T-01-03）

> 状态：**已生成（合成数据）**。用户无法提供真实业务扫描件，授权自行生成；
> 数据由 `scripts/gen_golden.py` 渲染，transcripts 为渲染源文本（等价人工校对底稿）。
> **局限：非真实业务扫描，V-01-05 结论仅代表合成样本上的字符准确率。**

## 目录约定

```
golden/
  scans/        20 页真实扫描件（jpg/png/pdf，建议 200-300dpi）
  transcripts/  与 scans 一一对应的人工校对文本（UTF-8，文件名同主名）
  tables/       含跨页/合并单元格的复杂表格扫描件 + 校对后的单元格矩阵（csv）
  manifest.csv  标注来源、校对人与时间
```

## manifest.csv 字段

| 字段 | 说明 |
|---|---|
| page_file | `scans/` 下文件名 |
| transcript_file | `transcripts/` 下文件名 |
| source | 样本来源（业务场景/脱敏说明） |
| corrected_by | 人工校对责任人 |
| corrected_at | 校对日期（YYYY-MM-DD） |
| notes | 备注（印章、手写、污损等） |

## 验收口径（V-01-05）

- 20 页逐页计算字符准确率：`1 - 编辑距离 / 标注字符数`，加权平均 ≥ 98%。
- 复杂表格结构（行列数、合并单元格）正确率 ≥ 90%（T-01-07）。
- 禁止为达标调整 `drop_score`/质量阈值；不达标如实报告。

## 合成数据集说明

- 20 页覆盖贷款申请、资产负债、银行流水、购销合同、营业执照、财务报表、纳税、征信、抵押物（含跨页续表）、保证人、工资、应收账款、审批意见（合并表头）、风险提示、贷后检查、还款计划、费用、签署页。
- 每页 300dpi、轻微旋转/噪声/光照不均，模拟扫描件；无文本层，必须经 OCR。
